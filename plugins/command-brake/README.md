# 위험 명령 브레이크 (command-brake)

클로드가 되돌리기 어려운 명령을 실행하기 직전에 멈추고 한국어로 묻는다:

```text
위험 명령 브레이크 · 파일 삭제
왜: 효과음 적게 버전 복사본 지우기          ← 클로드가 명령에 붙인 설명
지울 것 1개:
  · s7_영상_효과음적게.mp4   (…/04_s7_클로드루틴/ 안)
되돌리기: 휴지통을 거치지 않아 되돌릴 수 없습니다.
⚠ 경로가 변수($…)로 적혀 있어 실행할 때 정해집니다. 변수가 비면 엉뚱한 곳을 지울 수 있어요.
명령 원문: rm "$D/s7_영상_효과음적게.mp4"
이 명령을 실행할까요?   1. 실행   2. 거절
```

> 0.2.0 (2026-10-07): 명령어 원문만 보여 주면 무슨 내용인지 모른다는 피드백으로 —
> 파일 하나 지우기(`rm`)·`find -delete`·코드 안 삭제도 잡고, **무엇을 · 왜 · 되돌릴 수 있나**를 먼저 보여 준다.
> 임시 폴더(`/tmp`)만 지우는 정리는 묻지 않는다.

거절하면 실행하지 않고, 클로드에게 "다른 방법으로 우회하기 전에 먼저 물어보라"고 전한다.

잡는 명령: 파일 삭제(`rm`)·폴더째 삭제(`rm -r`·`rm -rf`)·찾은 파일 한꺼번에 삭제(`find -delete`)·코드 안 삭제(`rmtree`·`os.remove` 등) · 저장 안 한 변경 지우기(`git reset --hard`) · 원격 기록 덮어쓰기(`git push -f`·`--force`) ·
추적 안 하는 파일 삭제(`git clean -f`) · 고친 내용 전부 되돌리기(`git checkout .`) · 디스크 포맷 · 디스크에 직접 쓰기(`dd of=`) ·
모든 권한 열기(`chmod -R 777`) · 데이터베이스 삭제(`DROP TABLE`)

## 한계

- 목록에 없는 표기는 잡지 못한다. 클로드 코드의 원래 권한 확인 창을 대신하지 않는다(에어백이지 안전벨트가 아니다).
- 묻을 사람이 없는 실행(`claude -p`·cron)에서는 끼어들지 않는다.
- 브레이크가 고장 나면 그 명령은 실행하지 않는다(실패 시 닫힘).

## 켜는 법

```bash
claude --plugin-dir ~/mods/command-brake
```

## 이 모드가 하는 일 (`claude plugin validate`)

```text
hooks: session.start, tool.call{tool=Bash}
calls: $.ui.ask
```
